# Orchestrator context intake

Use the analysis package as the primary planning input.

1. Read `.docs/` only to add executable detail to Jira issues and handoffs.
2. Preserve Brain's scope, architecture direction, constraints, risks, and acceptance criteria.
3. Convert document evidence into a concise `context-summary`; never give specialists raw document
   paths or direct `.docs/` access.
4. Mark a conflict instead of silently changing analysis.
5. Read source only when file ownership, current contract, or validation commands must be named in a
   handoff.
