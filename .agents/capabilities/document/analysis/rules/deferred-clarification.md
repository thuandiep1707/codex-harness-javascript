# Deferred Clarification

Clarification must not unnecessarily block analysis.

When an uncertainty is found:

1. record it;
2. continue every part of the analysis that does not depend on it;
3. finish all resolvable scope first;
4. collect the remaining questions into a clarification checkpoint;
5. after answers arrive, complete only the pending affected parts.

Example:

```text
A → clear → complete
B → uncertain → record and defer
C → clear → complete
        ↓
collect questions for B
        ↓
clarify
        ↓
complete B
```

Only stop immediately when the uncertainty genuinely prevents all meaningful remaining work.
