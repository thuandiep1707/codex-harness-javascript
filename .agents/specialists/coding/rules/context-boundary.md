# Coding context boundary

- Never open, search, summarize, or quote `.docs/`.
- Search product source only within the transient handoff's allowed scope.
- Use the transient issue handoff and approved dependency/design evidence as requirements.
- Do not compensate for missing requirements with chat history, `.analysis/`, or broad repository archaeology.
- Return an explicit blocker for missing authority, architecture, design, dependency approval, or write scope.
- Do not update Jira or create a local workflow/progress store.
