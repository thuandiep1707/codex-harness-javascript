# Agent System Analysis

This repository contains reusable Codex frontend-agent rules and skills rather than an application
bounded context. Application repositories adopting this base should provide their own approved
architecture and context analysis files.

## Available reports

- [Skill audit](report-skill.md)
- [Skill flow audit](report-skill-flow.md)

Do not treat these reports as application architecture decisions. They document the imported agent
system and support maintenance of its routing, gates, and skill composition.
